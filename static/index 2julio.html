Requisitos y configuración
Requisitos en MySQL 5.7:
log_bin=ON · binlog_format=ROW · binlog_row_image=FULL

Privilegios necesarios:
GRANT REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO 'tu_usuario'@'%';

Dependencia Python:
pip install pymysql-replication

Cómo funciona: FastAPI se conecta como esclavo silencioso (server_id=100). Lee eventos INSERT/UPDATE/DELETE del binlog en tiempo real sin afectar rendimiento. Los eventos se guardan en SQLite y se transmiten vía WebSocket.
